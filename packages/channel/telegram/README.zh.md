# @deepseek-ai/dsh-channel-telegram

[English](README.md) | 中文

## 概述

通往 agent 的 Telegram 通道：通过 Bot API 长轮询并将白名单聊天中继到持久会话。会话按聊天与话题键控，携带 origin telegram，并通过节流编辑流式回复。
